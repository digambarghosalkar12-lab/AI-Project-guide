# Working Copy Rule

Never edit master GUIDE.md, template/, or STATE.template.yaml files during normal project development.

For a build:
1. Create a working directory for the capability.
2. Copy the relevant template and STATE.template.yaml.
3. Load GLOBAL-RULES.md + current GUIDE.md + current working template/state + minimum parent checkpoint.
4. Conduct discussion and update only the working files.
5. On approval, generate artifacts into the project's actual component/plugin structure.
6. Validate/test, record verified state, compact, and return to the parent Builder when applicable.
