# Workflow

Extracted Production Candidate
  -> Map project hierarchy and dependencies
  -> Create compact global project context
  -> Select next component in hierarchy
  -> Load component + parent chain + relevant dependencies
  -> Derive relevant security and engineering checks
  -> Evaluate with evidence
  -> Write review/<mirrored-path>/<component>-security-improvement.md
  -> Persist compact findings and state
  -> Clear detailed component context
  -> Continue
  -> Targeted recheck when later evidence affects an earlier component
  -> Complete review index/state

The component is advisory only. It never implements recommendations.
