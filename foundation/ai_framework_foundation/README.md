# AI Development Framework Foundation

This package contains the locked project foundation and guide agreed during planning.

## Start Here
1. Read `PROJECT.md` for the project map.
2. Read `GLOBAL-RULES.md` for mandatory AI operating rules.
3. Copy `components/_template/` when creating a component.
4. Use `GUIDE.md` for the end-to-end operating model.
5. Capability builders live under `capability-builders/` and are designed one at a time.

## Core Principle
Build the project as small independently understandable components; give each AI only the agent, skill, tools, instructions, and state required for its current operation; protect context capacity; independently verify work; and keep evaluation separated from modification.
