# Capability Builders

Builders help an engineer create AI capabilities through a structured discussion with AI.

Common flow:
1. Start from raw template.
2. AI reads populated fields.
3. AI asks only for missing information.
4. Engineer and AI refine intent and boundaries.
5. Complete specification.
6. Engineer reviews it.
7. Generate capability.
8. Test independently.
9. Verify.
10. Register/integrate into the target component.

Detailed builders are intentionally designed one at a time.
